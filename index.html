Universal Automatic Regression Analyzer

자동 회귀 분석 및 머신러닝 모델 비교 시스템

프로젝트 소개

다양한 형태의 표 데이터를 입력하면 데이터를 자동으로 전처리하고, 여러 회귀 모델을 학습하여 성능을 비교하는 분석 프로그램입니다.

프로젝트 목적

사용자가 복잡한 머신러닝 코드를 직접 수정하지 않아도 CSV, Excel 등의 데이터를 이용하여 여러 회귀 모델을 자동으로 비교할 수 있도록 하는 것을 목표로 합니다.

사용한 모델

1. Linear Regression

입력 변수와 목표 변수 사이의 선형적인 관계를 분석합니다.

2. Polynomial Regression

2차 다항식을 이용하여 비선형적인 관계를 표현합니다.

3. Random Forest Regression

여러 개의 결정 트리를 결합하여 복잡한 비선형 관계를 분석합니다.

4. Gradient Boosting Regression

여러 약한 학습기를 순차적으로 학습하여 예측 성능을 높입니다.

데이터 처리 과정

  1. CSV, XLSX, JSON 파일 불러오기
  2. 데이터 기본 정보 확인
  3. ID 및 불필요한 변수 탐지
  4. Target 변수 자동 탐색
  5. 결측값 처리
  6. 범주형 변수 One-Hot Encoding
  7. 수치형 변수 Scaling
  8. Train / Test 데이터 분리
  9. 여러 회귀 모델 학습
  10. 모델 성능 비교

평가 지표

  • R² Score
  • MAE
  • RMSE

실행 환경

Python / Google Colab / scikit-learn / pandas / NumPy
